# UI kit: iGarden iOS app

Interactive recreation of the app's core screens, built from the SwiftUI source (see ../../github.md screen map).

- `index.html` — click-through demo (onboarding → plant list → detail → new-plant form → Smart hage)
- `App.jsx` — navigation state + fake garden data
- `PhoneFrame.jsx` — 390px iOS chrome (status bar, sheet presentation)
- `PlantListScreen.jsx` («Mine planter»), `PlantDetailScreen.jsx`, `PlantFormScreen.jsx` («Ny plante»), `SmartGardenScreen.jsx` («Smart hage»), `OnboardingScreen.jsx`

Plant photos are leaf placeholders — the real app shows user photos. Icons are Lucide (SF Symbols substitute).
