Lucide glyph wrapper standing in for SF Symbols; use for every icon in iGarden UI.

```jsx
<Icon name="droplet" filled color="var(--action-water)" size={16} />
```

Requires `<script src="https://unpkg.com/lucide@0.462.0/dist/umd/lucide.js"></script>` on the page.
SF Symbol mapping: drop.fill→droplet(filled), leaf→leaf, sun.max→sun, cloud→cloud, cloud.sun→cloud-sun, bell→bell, plus→plus, camera→camera, scissors→scissors, sparkles→sparkles, person.2→users, person.crop.circle→circle-user, magnifyingglass→search, checkmark→check, checkmark.seal.fill→badge-check(filled), exclamationmark.triangle.fill→triangle-alert(filled), trash→trash-2, arrow.up.arrow.down→arrow-up-down, ellipsis.circle→ellipsis, play.circle.fill→circle-play(filled), gauge.with.needle→gauge, photo.on.rectangle→images, square.and.arrow.up→share, chevron.right→chevron-right, minus.circle.fill→circle-minus(filled), drop.triangle.fill→triangle-alert(filled).
