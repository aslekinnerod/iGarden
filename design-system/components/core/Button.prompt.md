iOS-style button in the four styles the app uses; labels are Norwegian sentence case.

```jsx
<Button size="large" fullWidth icon="droplet">Vannet nå</Button>
<Button variant="plain">Rediger</Button>
<Button variant="destructive">Slett plante</Button>
```

`prominent` = filled accent green (.borderedProminent); `bordered` = 12 % green tint; `plain`/`destructive` = bare text (list buttons). `size="large"` for sheet CTAs («Kom i gang»).
